## 分歧风险说明

1. **U3 的 E1=1**：手册 E1=0 锚点措辞（"报告方自主决定、监管方无独立凭据"）与 U3 材料高度吻合，但材料用的是"公开材料未显示运行期机制"，按判定原则1（未显示≠明确称无）、原则3（核验由被规制方完成最高赋1）、原则5（1 与 0 间向 1 靠拢）最终取 1。
2. **U3 的 D1=?**："未显示裁量边界的公开说明"与 D1=0 锚点"未披露裁量边界"接近，但材料通篇为"公开材料未显示"式表述，按原则1（材料不足以判断）取 ? 而非 0。
3. **U6 的 S2=1**：IP/用户代理"仅作运行环境快照、未据此自动改变权限"近似 S2=2 锚点的"仅记录外部引用、不担保"，但材料无 GOV-1 式明确的机器/社会担保两分，按原则5（2 与 1 间取 1）赋 1。
4. **U6 的 E1=2**：API 网关每次请求鉴权并返回 403 属运行期强制拒绝，但材料未明确鉴权拒绝被单独留痕、日志是否可被外部查验，E1=2 的"有记录、可查验"要件存在疑义。
5. **U1 的 E2=2**：audit_id 给出可独立验算的 sha256 计算方式，满足 E2=2 锚点，但模板层事件存储为内存字典、无跨进程持久化，对痕迹的持续可核查性构成疑义。
