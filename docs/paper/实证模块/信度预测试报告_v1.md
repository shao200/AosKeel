# 编码手册信度预测试报告（v1.0）

**日期**：2026-11-21
**对象**：边界可见性四维度编码手册 v1.0 → v1.1
**编码对象**：6 个（U1 AosKeel、U2 欧盟AI法案、U3 美国行政令、U4 中国备案＋评估、U5 英国AISI、U6 构造RBAC情景），共 48 个编码单元
**指标**：8 个（S1/S2/E1/E2/D1/D2/A1/A2）

---

## 一、方法的性质与边界（先说清楚）

**本轮不是评分者间信度（inter-rater reliability）检验。** 三名独立编码者 C1/C2/C3 是人工智能体，不是人类研究者。同模型编码者共享训练与推理模式，其一致性会系统性高于人类编码者之间的一致性。因此：

- 本轮的合法用途是：**检验编码手册的操作化程度**（规则是否清晰到可被稳定执行）、**识别定义歧义**、以及**产出可直接交付人类编码者的完整材料包**。
- 本轮结果**不能**作为"边界可见性编码具有良好信度"的证据写入论文正文的实证结论。它只能作为"编码手册经过预测试、歧义已修订"的方法学说明。
- 正式信度检验须由 ≥2 名人类编码者对同一材料包独立编码后计算，列入论文研究议程。

作者本人（C0）在手册定稿后独立完成一套编码，与独立编码者比较，用于探查作者偏差方向。

---

## 二、执行流程

1. **C0 编码**：作者依 v1.0 手册完成 48 单元赋值。
2. **首轮盲编码**：C1/C2/C3 各自仅获准读取手册 v1.0 与材料包 v1，不得联网、不得读取作者编码或论文正文，独立赋值。
3. **信度计算**：简单一致率、两两 Cohen's κ、Krippendorff's ordinal α（缺失值按 `?` 排除）。
4. **歧义定位**：首轮分歧集中在 3 个单元，全部指向手册措辞而非实质判断。
5. **手册修订**：v1.1 强化判定原则1，并新增 E1/D1/D2 三处澄清。
6. **第二轮重测**：同一批编码者在不知彼此结果的情况下按 v1.1 重新赋值，写入 `_R2` 文件。

## 四、如何解读 α 从 0.9223 到 1.0000

**不能解读为"概念更可靠了"。** 准确解读是：

1. 首轮分歧的 3 个单元全部源于手册**定义缺口**，不是编码者对同一规则的不同实质判断。修订补齐了缺口，故同样材料产生同一赋值——这说明**手册的操作化定义已足够明确**，预测试达到目的。
2. 第二轮 α=1.0 是在手册设计者（作者）依据首轮分歧**选定解释**后取得的。这带有循环：是作者判断哪种解释正确，再写入手册，编码者照新规则执行。因此 α=1.0 是**规则澄清的产物**，而非独立发现。论文不得把它写成"信度已验证"。
3. 同一模型编码者的一致性不能外推到人类编码者。人类编码者会带入学科训练、理论立场与阅读习惯差异，预期 α 会低于本轮。
4. 作者（C0）与独立编码者之间始终存在 residual 分歧（二轮 κ≈0.78–0.80），集中在 U3（美国模式的 E1/D1/D2）与 U6 的 S2。这提示作者编码带有系统性倾向——本轮材料中作者倾向把"材料未显示"读作 `0` 或 `?`，而独立编码者倾向按"有义务措辞"赋 `1`。**这是反身性说明应报告的具体发现，不能隐去。**

## 五、对论文的实际推进

本轮把论文 v0.2 中"编码由作者一人完成、存在主观性"这一弱点，做了三层实质改进：

1. **从单人编码 → 多编码者独立赋值 + 信度量化**：即使编码者非人类，程序上已建立可复用的编码脚本与量化指标。
2. **从"编码结果" → "编码规则的可修订性"**：3 处歧义被定位并修订，第四章编码表不再是不可质疑的作者判断。
3. **从"未操作化" → "可交付人类编码者的完整包"**：手册 v1.1、材料包、原始结果、计算脚本齐备，正式信度检验只需替换编码者。

**仍不能解决的问题**：经验证据的**外部效度**与**命题的因果检验**。编码信度再高也不证明"范畴错误"是正确的诊断——它只保证"如果采用此框架，不同人会得出相同编码"。O1–O3 的证据评估（见《三后果证据评估_v1.md》）处理的是另一半问题，且结论是"相容但未证实"。
