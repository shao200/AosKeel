三条诚实边界

① AOS 不是知识图谱系统。事实不是 RDF 三元组，读路径不是 SPARQL，而是 append-only 事件流 + 可重建的只读投影。TBox/ABox 是教学类比。
② 模板不制造治理世界事件。创制任命、steward 资格、审批与红队属现实世界事件，模板只记录引用；bootstrap --stage 2/3 返回拒绝。
③ 事件存储是纯内存。进程退出即失；生产实例须自接持久化并自行证明 append-only 与审计持久性。wheel 也不是可安装交付物。

最短入口（模板根）

pip install -e .        # pyyaml + pytest
aos verify              # 结构 → 哈希 → 注册
aos test                # 28 条布线路径
aos init my-org-system  # 之后在实例内用 python src/cli/main.py ...
核对口径：以上命令与输出在 v0.3.0 源码树及新建实例中实测通过。docs/guide/ 随 aos init 复制到实例；本页与指南均不在哈希覆盖域，改动不影响签发摘要。
